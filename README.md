## 🚀 Featured Projects

### DOOZY SPAM BOT
A powerful and stable Telegram spam bot built with **Telethon**. This repository serves as the deployment configuration wrapper for Heroku.

**Tech Stack:**
- Python 3 with asyncio
- Telethon 1.24.0
- SQLAlchemy + PostgreSQL
- Heroku deployment

📦 **Key Features:**
- Multi-bot token support (up to 10 tokens)
- Custom command handlers
- Database integration
- Self-updating capability via Heroku API
- Environment-based configuration
